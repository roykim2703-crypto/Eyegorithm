# Bagatree 기획서

## 1. 프로젝트 개요

-   **프로젝트명:** Bagatree
-   **학번 / 성명:** 10601 / 김민균
-   **구현 도구:** Processing

자료구조와 알고리즘의 추상적인 동작 원리를 자막이나 음성 해설 없이
움직임, 색, 형태, 리듬, 효과음 등의 영상 언어로 표현한다. 자료구조
내부의 숫자 값은 표시할 수 있지만 알고리즘을 직접 설명하는 자막이나
나레이션은 사용하지 않는다.

## 2. 선택한 자료구조

### 트리

트리에서 값을 비교하여 왼쪽 또는 오른쪽으로 이동하는 모습이 핀볼에서
공이 핀을 만나 좌우로 떨어지는 모습과 비슷하다는 점에서 아이디어를
얻었다. 숫자마다 크기가 다른 공을 핀볼 형태의 판에 떨어뜨려 트리의
구조와 동작을 시각화한다.

## 3. 핵심 시각화 규칙

``` text
공 < 핀 → 왼쪽
공 = 핀 → 가운데
공 > 핀 → 오른쪽
```

공은 이동한 방향에 있는 다음 핀과 다시 비교하며 이 과정을 반복한다. 공이
이동할 방향에 맞춰 핀볼 스타일의 화살표가 반짝여 비교 결과를 시각적으로
보여준다.

## 4. 트리 연결선

배경에는 각 핀을 **트리 구조 형태로 연결하는 선**을 표시한다.

``` text
          [핀]
         /    \
      [핀]    [핀]
      / \      / \
   [핀][핀] [핀][핀]
```

연결선은 두 가지 역할을 가진다.

1.  핀들이 실제 트리 구조를 이루고 있다는 것을 시각적으로 보여준다.
2.  삭제 연출에서 파괴된 핀의 조각이 이동하는 통로로 사용한다.

따라서 연결선은 단순한 배경 장식이 아니라 트리 구조와 애니메이션을
동시에 표현하는 요소이다.

## 5. 삽입 (Insert)

새로운 숫자를 가진 공을 위에서 떨어뜨린다. 공은 핀과 충돌할 때마다 값을
비교하여 왼쪽 또는 오른쪽으로 이동한다.

``` text
공 투입
↓
핀과 충돌
↓
값 비교
↓
좌 / 우 / 중앙 이동
↓
다음 핀
↓
반복
```

공이 삽입될 위치에 도착하면 **공이 새로운 핀으로 변한다.** 이를 통해
새로운 값이 트리에 삽입되었다는 것을 설명 없이 보여준다.

## 6. 삭제 (Delete)

삭제할 값을 가진 공이 트리를 따라 이동하여 삭제 대상 핀에 도달한다.
대상에 도달하면 해당 핀이 파괴된다.

### 핀 파괴

``` text
삭제 공 도착
↓
삭제 대상 핀 충돌
↓
핀 파괴
↓
핀 파편 발생
```

### 연결선을 이용한 회수 연출

파괴된 핀의 조각은 단순히 사라지지 않는다. 조각들이 **트리 연결선 내부로
들어간 뒤 연결선을 통로처럼 타고 위쪽으로 올라간다.**

``` text
핀 파괴
↓
파편 생성
↓
파편이 연결선 내부로 진입
↓
트리 연결선을 따라 이동
↓
위쪽으로 상승
```

평소에는 트리 구조를 보여주던 연결선이 삭제 순간에는 실제 이펙트의 이동
경로로 사용된다.

## 7. 탐색 (Search)

탐색용 공을 떨어뜨리고 핀의 값과 비교하면서 트리를 이동한다.

``` text
탐색 공
↓
핀과 값 비교
↓
좌 / 우 이동
↓
반복
↓
같은 값 발견
```

찾는 값에 도달하면 해당 핀과 연결되는 연출을 사용하여 핀 자체를 변경하지
않고 위치만 찾았다는 것을 보여준다.

## 8. 물리 기반 연출

공을 기계적으로 좌우 이동시키기보다 물리엔진을 적용한 핀볼 느낌을
사용한다. 핀과 공의 값이 비슷할수록 공이 핀을 아슬아슬하게 넘어가는
움직임을 연출하여 비교 결과를 물리적인 움직임으로 표현한다.

## 9. 미적 요소

-   반짝이는 핀볼 스타일 배경
-   트리 형태의 핀 연결선
-   이동 방향에 따라 반짝이는 화살표
-   쇠구슬 형태의 공
-   핀과 공의 충돌 효과 및 효과음
-   핀 파괴 효과
-   연결선을 따라 위로 이동하는 삭제 파편
-   핀볼에 어울리는 배경음악

## 10. 영상 제작

최종 영상은 약 **1\~2분**을 목표로 한다.

주요 촬영 장면: - 숫자를 입력하는 장면 - 공이 떨어지는 장면 - 핀과 공이
충돌하고 상호작용하는 장면 - 삽입 / 삭제 / 탐색 과정 - 삭제된 핀의
파편이 연결선을 따라 위로 올라가는 장면

반복되는 부분은 배속을 사용하여 시간을 조절한다. 자막, 설명 텍스트, 음성
나레이션 없이 움직임, 색, 형태, 전환, 효과음과 배경음악으로 알고리즘의
흐름을 전달한다.

-   알고리즘을 설명 없이 시각적으로 전달하는 방법 학습
